# Dance Fit Space — прототип сайта (webpack)

Три страницы по макету Figma, у каждой свой HTML, JS и CSS:

| Страница | HTML | JS | CSS |
| --- | --- | --- | --- |
| Расписание | `src/index.html` | `src/javascripts/schedule.js` | `src/stylesheets/schedule.css` |
| Абонементы и цены | `src/pages/prices.html` | `src/javascripts/prices.js` | `src/stylesheets/prices.css` |
| Запись (окно заявки) | `src/pages/booking.html` | `src/javascripts/booking.js` | `src/stylesheets/booking.css` |

Общее: `base.css` (меню, подвал, кнопки, заголовок страницы), `reset.css`, `layout.css` (шрифт Inter).

Сценарий: Расписание → клик по занятию → «Записаться» → окно заявки (3 шага) → «Заявка отправлена!».
Или: Цены → строка цены → окно заявки.

## Запуск
```bash
yarn
yarn start
yarn build
```
